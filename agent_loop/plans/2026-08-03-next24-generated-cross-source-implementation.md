# NEXT24 Cross-Source Generated-Structure Screening Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Seal a strictly label-free transport application of the frozen
NEXT23 B+E law to the existing SSAGEN x0 cohort, then evaluate it only when an
independent DFT endpoint becomes available.

**Architecture:** Add a source-specific geometry sanitizer, a generic
selected-source frozen-rule applier, and an identical-cohort Pauling runner.
Reuse the tested NEXT20 and NEXT22 analytic feature builders.  Keep
identifier-bearing artifacts outside the repository and publish only additive
aggregate evidence and a new standalone report.

**Tech Stack:** Python 3.11, pandas, NumPy, ASE, pymatgen, pytest, Parquet,
deterministic ZIP/JSON manifests.

### Task 1: Canonical SSAGEN x0 sanitizer

**Files:**
- Create: `tests/test_next24_ssagen_holdout.py`
- Create: `src/next24_ssagen_holdout.py`

Write failing tests for strict upstream protocol/hash validation, projected
metadata, per-frame hashes, exact ID coverage, formula/atom-count checks,
canonical deterministic archive generation, numeric geometry preservation,
no-replace publication, and input/source rehash before publication.  Implement
the minimum sanitizer and run the focused test with NEXT11/NEXT12 regression
tests.

### Task 2: Frozen selected-source applier

**Files:**
- Create: `tests/test_next24_apply_rule.py`
- Create: `src/next24_apply_rule.py`

Write failing tests for immutable NEXT23-law validation, automatic loading of
only the feature sources selected by the frozen formula, exact cohort/feature
ID and metadata-hash joins, fail-open unsupported rows, forbidden endpoint/DFT
columns, no endpoint argument, no-replace publication, and prediction/source
rehash.  Implement without changing NEXT23 code or parameters.

### Task 3: Identical-cohort Pauling controls

**Files:**
- Create: `tests/test_next24_pauling_controls.py`
- Create: `src/next24_pauling_controls.py`

Write failing tests for canonical cohort validation, unchanged Pauling 2--5
definitions, per-rule fail-open decisions, combined decision, exact row
accounting, and no-replace/hash-closed publication.  Implement by reusing the
existing classical feature calculator and decision functions.

### Task 4: Execute and seal prediction-only artifacts

Create external no-replace directories for canonical SSAGEN x0, SIVR, SCBVE,
frozen predictions, and Pauling controls.  Execute in that order.  Verify that
all prediction manifests say labels/endpoints/relaxed structures were unopened,
no model or proxy potential was used, coordinates/cells were unmodified, and
the frozen NEXT23 threshold was not refit.

### Task 5: Seek an eligible DFT endpoint

Audit the existing NEXT12 VASP queue and the host for completed outputs or an
available VASP runner.  In parallel with local artifact sealing, search primary
paper repositories and official data releases for downloadable, per-structure
paired generated x0 and DFT-relaxed final structures/results.  Reject MLFF-only,
aggregate-only, relaxed-only, and unpaired datasets.  Do not substitute a
proxy endpoint.

### Task 6: Evaluation and standalone report

If a valid endpoint exists, first verify that the prediction timestamp/hash
predates label opening, then add a no-refit evaluator and tests for DFT
failure/reorganization metrics and identical-cohort Pauling comparisons.  If
no endpoint exists, preserve the prediction-only state and state the evidence
gap explicitly.  Run focused tests, the full repository suite, CodeGraph
status, independent hash/formula recomputation, forbidden-token scans, and ZIP
integrity checks.  Write a new standalone NEXT24 report.  Do not modify any
existing report or paper before user confirmation.
