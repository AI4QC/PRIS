# NEXT59 ODAC23 motif-augmented discovery search

NEXT59 is the second discovery-only pass motivated by the documented NEXT57
failure.  It reuses the exact NEXT57 endpoint, framework domain gate,
standardization, stratum definition, direction rule, finite formula catalogue,
threshold grid, one-sided Wilson gates, ranking, and canonical tie-break.

The only expansion is the candidate catalogue: all 56 NEXT55 analytic features
plus all 65 frozen NEXT58 shared-motif features, for 121 explicit x0-only terms.
The top-20 pair and top-12 triple shortlist sizes are unchanged.  No feature is
fit or learned, and formulas remain one to three normalized additive terms.

The process accepts only the already exposed discovery label file.  Internal
validation, internal replication, official validation, test, and OOD paths are
not arguments.  A passing candidate is sealed before any internal-validation
label is opened.  A failure remains diagnostic and cannot advance.
