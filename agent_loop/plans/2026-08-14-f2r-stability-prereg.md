# PREREG-F2R: rebuilding the experimental-domain e_hull ranking formula (fixing F2's irreproducibility and pushing for higher accuracy)

## 1. Motivation

The paper acknowledges that F2's 0.5725/0.7313 is "the only number at present that cannot be
regenerated from the archived feature tables" (the within-fold standardisation statistics were
not saved). This chain: (a) rebuilds the stability formula under a reproducible protocol; and
(b) uses an enlarged feature pool (symmetry + classical Born terms + density) to push for a
higher group-equal accuracy.

## 2. Data and splits (in existence before this pre-registration, unchanged)

- `real_rank.parquet` merged with the phys/elec/geom features (the same convention as
  `formula2.load()`, dropping lockbox rows and rows of unknown split), plus the new
  `real_rank_aug.parquet` (the 13 new features defined exactly as in PREREG-F3 section 4,
  generated by `f6_features.py`).
- Fitting uses `split == discovery` only; the imputation medians and standardisation statistics
  come from discovery alone and are applied to calibration once frozen.
- Evaluation is on the composition groups with `split == calibration`; the label is the
  within-group e_hull ranking and the metric is the S13 group-equal accuracy (the same
  implementation as `rank_rulesets.evaluate`).
- Calibration has been adaptively reused earlier in this repository's history; the numbers from
  this chain carry the same qualifier, consistent with how the paper describes calibration. The
  lockbox is not touched.

## 3. Procedure (frozen; the same model class as PREREG-F3 section 5)

- All within-group pairs (pairs with strictly unequal e_hull), X = z(lower hull) - z(higher
  hull), y = 1, weighted 1/(pairs in group); an antisymmetric logistic with no intercept.
- Greedy forward selection: 5-fold GroupKFold within discovery (grouped by composition), scored
  by group-equal accuracy on the validation fold; stop when the gain falls below 0.002 or at 8
  terms. Refit on all of discovery, then freeze.
- F2R-full (an L2 fit on all features) is also emitted as an upper reference.
- **The restated-F2 baseline**: the paper's seven coefficients unchanged, with z statistics taken
  from discovery (frozen) and evaluated on calibration -- this is the "regenerable F2", compared
  pairwise against the new formula.

## 4. Success gates (frozen)

- H1: the 95% lower bound of acc(F2R) - acc(restated F2) on calibration, by group-clustered
  bootstrap (B=2000, seed 20260728), is above 0
- H2: acc(F2R) exceeds bl_min alone and vol_per_atom alone (point estimates)
- H3: whether or not H1 passes, archive every fold statistic and the frozen z statistics so that
  each number is regenerable, and rewrite the paper's F2 paragraph in regenerable terms

Wording, graded: if H1 passes, "a regenerable seven-or-fewer-term score improves on F2"; if H1
fails, "F2 restated regenerably; no material gain from the enlarged pool". Either way it goes
into the paper (a negative result is reported as it is).

## Added chain F2R-G (2026-08-14, a new chain; reuse of calibration disclosed)

Goal: push the group-equal accuracy on the gap-resolvable region (|dE_hull| >= 25 meV/atom) to
0.80.
Procedure: exactly the same model class, feature pool and greedy procedure as F2R, differing in
two places only -- (a) the pairs used for fitting and CV scoring are restricted to
|dE| >= 25 meV; (b) the calibration evaluation is restricted to the same pair set (group-equal,
with a clustered bootstrap CI). One evaluation after freezing, output to
outputs/20260814_f2rg_gap25/.
Gate: G-gap = group-equal acc >= 0.80 (point estimate). If it is not reached, report the
operating point and CI actually achieved, and compare it pairwise against F2R's
0.7438 [0.675, 0.808] over the same pair set.
This chain's CALIB_CONTACT is independent of F2R's; the cumulative reuse count of calibration is
disclosed in the SI.
