## Literature and repository novelty

Coordination sequences count distinct vertices at successive graph distances
in an infinite periodic crystal graph.  They are established topological net
indices and, for periodic crystals, have quasi-polynomial growth.  The 2024
skeletal-net hierarchy additionally motivates removing weak contacts while
preserving the long-range periodic skeleton.

The existing repository includes fixed-graph translation ranks (NEXT166),
local and weighted directional rigidity, strong-neighbourhood closure,
Voronoi/Delaunay shape and topology summaries, local angular persistence,
void-network bottlenecks, force closure, charge/bond-valence graph operators,
coordination reciprocity (NEXT375), and the threshold for first attaining
translation rank three (NEXT379).  It does not count convergence of distinct
non-backtracking walks onto the same lifted periodic vertex.  Such convergence
is the finite-shell signature of rings and alternative routes: a tree has no
collisions, while a redundant periodic net has multiple routes to the same
atom image.

## Frozen graph construction

1. Accept an ASE `Atoms` object only when it has at least one site, finite
   nonsingular cell and positions, `pbc == (True, True, True)`, no calculator,
   empty `info`, and exactly the `numbers` and `positions` arrays.
2. Apply the already frozen NEXT267 Minkowski reduction and wrapping.
3. Construct ordinary periodic `VoronoiNN(weight="solid_angle", tol=0,
   cutoff=13)` facets.  Each directed key is `(i,j,T)` with integer image
   `T`.  A key must have the reverse `(j,i,-T)`.  Reverse solid angles must
   differ by at most `1e-8`; use their arithmetic mean `omega_e`.
4. For each site define `Omega_i = max_(e incident from i) omega_e`.  The
   mutual local salience of an undirected edge `e=(i,j,T)` is

       s_e = min(omega_e/Omega_i, omega_e/Omega_j).

   Quantize `s_e` on the fixed `1e-10` grid.  Process exact salience ties as a
   batch in decreasing order.
5. Use exact integer quotient-graph potentials and cycle-closure translations
   to assign every site its NEXT379 bottleneck `b_i`: the largest threshold at
   which its component first has translation rank three, or zero if it never
   does.  Freeze the global skeleton threshold as the inverted-CDF site
   quantile

       tau = q10_i b_i.

   This is the unchanged, pre-outcome NEXT379 threshold definition.  The
   NEXT383 skeleton contains exactly edges with `s_e >= tau`, including the
   complete exact-tie batch.

## Sole frozen feature

For each crystallographic site `i`, lift the threshold graph to vertices
`(j,T)` in the infinite periodic graph.  Starting at `(i,0)`, enumerate all
non-backtracking walks of exactly three edges.  Immediate traversal of the
same edge in reverse is forbidden; revisiting a vertex by a longer route is
allowed.  Let `W_i` be the number of walks counted with multiplicity and
`E_i` the number of distinct lifted endpoint vertices.  Define

    c_i = 0                         if W_i = 0,
    c_i = 1 - E_i/W_i               otherwise.

Depth three is frozen because it is the first single depth that detects route
convergence generated by the common three-, four-, five- and six-member local
ring motifs without introducing a searched radius.  A non-branching periodic
chain has `c_i=0`; multiple routes that converge on the same atom image make
`c_i>0`.

The only output feature is

    pspc_skeletal_nb3_collision_q10
        = inverted-CDF q10_i c_i,

quantized on the `1e-10` grid.  Its only frozen direction is
`protected_high`: higher lower-tail route collision is interpreted as greater
topological path redundancy.  There is no second walk depth, graph threshold,
summary quantile, weight, direction, transform, conjunction or
source-specific choice.
